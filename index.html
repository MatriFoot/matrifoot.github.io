О себе

Проектирую и внедряю высоконагруженные Telegram-боты, автоматизированные системы и веб-интерфейсы. Работаю с современными технологиями: Python, Kotlin, TypeScript, SQL. Опыт коммерческой разработки с 2024 года. Открыт к сложным проектам и долгосрочному сотрудничеству.

Ключевые компетенции

Telegram-боты (aiogram, telebot)
Модерация и иерархии
Магазины и приём платежей
Веб-сайты и лендинги
API-интеграции
Базы данных (SQLite, PostgreSQL)

Услуги

  • Разработка Telegram-ботов любой сложности — от простых автоответчиков до многоуровневых систем с админ-панелями
  • Создание веб-сайтов и лендингов (HTML/CSS, адаптивная вёрстка, GitHub Pages)
  • Автоматизация бизнес-процессов через ботов и скрипты
  • Интеграция с внешними API, платёжными системами, CRM
  • Сбор и анализ статистики, системы логирования
  • Консультации и сопровождение проектов

Технологический стек

Языки: Python (основной), Kotlin, TypeScript

Библиотеки: aiogram, python-telegram-bot, Flask, FastAPI

Базы данных: SQLite, PostgreSQL, Redis

Инструменты: Git, Docker, Termux, GitHub Actions
